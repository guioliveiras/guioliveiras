## 📊 Featured project

### [People Intelligence](https://github.com/guioliveiras/people-intelligence) · [live demo →](https://guioliveiras.github.io/people-intelligence/)

**Workforce planning modeled as a supply chain.** A 25-screen analytics dashboard
backed by a reproducible Python pipeline.

<a href="https://guioliveiras.github.io/people-intelligence/">
  <img src="https://raw.githubusercontent.com/guioliveiras/people-intelligence/main/docs/img/exec-light.png" alt="People Intelligence dashboard" width="100%" />
</a>

| | |
|---|---|
| **The idea** | Demand forecasting → headcount need. Lead time → time to hire. Safety stock → succession bench. Stockout → open role, priced in R$ |
| **The data** | 10 years of monthly synthetic data — 6 departments, 34 roles, 3,099 employees, 84,527 ML observations — generated from a single seed |
| **The model** | Interpretable logistic regression with right-censoring handling. AUC 0.598, and the README explains why inflating that number would mean leakage, not a better model |
| **The build** | Vanilla HTML/CSS/JS, no framework, no bundler. Every chart is hand-drawn SVG |
| **The rigor** | 93 tests, CI that reruns the whole pipeline twice to prove determinism, WCAG AA contrast verified by measurement in both themes |
